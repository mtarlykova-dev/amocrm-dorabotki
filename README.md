# Доработка amoCRM: пожелание — как решаем

Страница с пожеланиями отдела продаж к amoCRM и способами решения. На каждой задаче можно ставить статус («Не начато» / «В работе» / «Готово») выбирать дедлайн и оставлять комментарии — они сохраняются в Google-таблицу и видны всем, кто открыл страницу.

## Файлы

- `index.html` — сама страница. Открывается через GitHub Pages.
- `Code.gs` — код Apps Script, который хранит статусы и комментарии в Google-таблице.

## Как подключить хранилище

1. Google-таблица → Расширения → Apps Script → вставить код из `Code.gs`, сохранить.
2. Развернуть → Новое развёртывание → «Веб-приложение». Выполнять от имени: «Я». Доступ: «Все».
3. Скопировать URL вида `https://script.google.com/macros/s/.../exec`.
4. В `index.html` вставить его в строку `var STATUS_URL="";`.

После изменения `Code.gs` нужно обновить развёртывание: Развернуть → Управление развёртываниями → карандаш → Версия: «Новая версия». Тогда URL не меняется.

## Как править содержимое

Все тексты лежат в массиве `DATA` внутри `index.html`: `w` — пожелание, `h` — как решаем, `t` — теги. Статусы и комментарии привязаны к номеру строки внутри раздела, поэтому новые пункты добавляйте в конец раздела или задайте им свой `id`.
