# Доработка amoCRM: пожелание — как решаем

Страница с пожеланиями отдела продаж к amoCRM и способами решения. На каждой задаче можно ставить статус («Не начато» / «В работе» / «Готово») выбирать дедлайн, оставлять комментарии и добавлять новые задачи — они сохраняются в Google-таблицу и видны всем, кто открыл страницу.

## Файлы

- `index.html` — сама страница. Открывается через GitHub Pages.
- `Code.gs` — код Apps Script, который хранит статусы и комментарии в Google-таблице.

## Как подключить хранилище

1. Google-таблица → Расширения → Apps Script → вставить код из `Code.gs`, сохранить.
2. Развернуть → Новое развёртывание → «Веб-приложение». Выполнять от имени: «Я». Доступ: «Все».
3. Скопировать URL вида `https://script.google.com/macros/s/.../exec`.
4. В `index.html` вставить его в строку `var STATUS_URL="";`.

После изменения `Code.gs` нужно обновить развёртывание: Развернуть → Управление развёртываниями → карандаш → Версия: «Новая версия». Тогда URL не меняется.

## Задачи, добавленные с сайта

Хранятся на листе «comments» Google-таблицы в строках с id `__tasks__` (текст задачи — в колонке text в формате JSON). Так они работают с любой версией скрипта, обновлять его не нужно. Чтобы удалить задачу — удалите её строку. Со страницы она пропадёт сама.

Если развёрнут новый `Code.gs` (ответ скрипта начинается с `{"v":4`), страница дополнительно читает лист «tasks».

## Как править содержимое

Все тексты лежат в массиве `DATA` внутри `index.html`: `w` — пожелание, `h` — как решаем, `t` — теги. Статусы и комментарии привязаны к номеру строки внутри раздела, поэтому новые пункты добавляйте в конец раздела или задайте им свой `id`.

## Вкладка «План работ»

Вторая вкладка (ссылка `…/#plan`) — рабочий план по блокам. Сейчас там блок 1 «Карточка компании» по итогам встречи 19 ноября: задачи по приоритетам, ответственные, дедлайны, подзадачи-чекбоксы, что решили, комментарии.

Данные блока — в объекте `K1` во втором `<script>` в `index.html`. Всё, что меняют на сайте, хранится в той же Google-таблице:
- статусы задач и подзадач — лист «status», id `k1-…`;
- дедлайны — лист «deadlines» (или «comments», если скрипт старый);
- смена ответственного или группы — лист «comments», id `__k1meta__`;
- предложенные задачи — `__k1tasks__`, добавленные подзадачи — `__k1subs__`.

Удалить предложенную задачу или подзадачу — удалить её строку на листе «comments».
